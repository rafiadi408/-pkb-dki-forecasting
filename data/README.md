# Dataset

Dataset bulanan PKB dan BBNKB yang digunakan dalam penelitian diperoleh melalui permohonan resmi kepada Bapenda Provinsi DKI Jakarta untuk kepentingan penelitian akademik.

Berdasarkan konfirmasi tertulis dari Bapenda, data yang diberikan hanya untuk kepentingan penelitian dan **tidak diperbolehkan untuk disebarkan secara publik**. Karena itu, dataset mentah tidak disertakan dalam repository ini.

Peneliti yang membutuhkan dataset perlu memperoleh akses melalui mekanisme resmi dari pemilik data.

Repository ini menyediakan kode dan dokumentasi analisis tanpa mendistribusikan data mentah tersebut.
